当人们谈论遗留系统现代化时，大多数人不会想到目标环境会是 Java 8。但这正是 **Nik Malykhin** 面临的挑战——他需要在当今的硬件上运行一套 Java 1.5 代码库。早期使用大语言模型时，虽然得到了看似合理的答案，但在实际代码库中却站不住脚。直到他将整个过程建立在证据基础上，利用人工智能辅助分析、在稳定的 Docker 环境中进行验证，并通过测试保护逐步重构，才取得了进展。核心经验非常务实：当人工智能受到证据、明确角色和分步现代化策略的约束时，它才最为有用。
